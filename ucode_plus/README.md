# uCode+ OpenRouter Integration

This directory contains the implementation of the **uCode+** module, which adds OpenRouter cloud model access to OK Assistant.

## Structure
```
ucode_plus/
├─ README.md          # Overview and usage
├─ ucode_plus.json    # Configuration schema (example)
├─ client.py          # Python client handling OpenRouter requests
└─ tests/
   └─ test_client.py # Unit tests for the client
```
