# The uDos Learning & Educational Philosophy

## 1. Audience & Pedagogical Focus

The uDos educational curriculum is designed for:
- Advanced primary school students exploring computational thinking for the first time.
- High school students seeking sovereign, transparent, and foundational programming skills.
- Adults and lifelong learners who want to learn to code in the traditional microcomputer BASIC way.

## 2. "The uDos Way" as the Universal Standard

Global knowledge and learning streams in uDos must strictly point back to the sovereign user flow:

### What We Do NOT Teach
- **No generic commercial IT setups**: We do not maintain guides on "how to install Windows and setup Microsoft Office".
- **No sprawling multi-language complexity for beginners**: We do not introduce complex Python environments, virtualenv debugging, Rust build tools, or C++ toolchains in beginner tracks. (These are advanced developer tools used in external environments like Antigravity).
- **No complex network troubleshooting**: We do not force students to debug home Wi-Fi subnets, DHCP server configurations, or cloud VPN tunnels.

### What We DO Teach (The uDos Way)
1. **Hardware Rebirth over Consumerism**:
   - "How to rebirth an old PC, decommissioned POS terminal, or library kiosk into a modern universal workstation using Sonic Screwdriver and CMMint."
2. **Traditional Procedural Coding with uCode & BBC BASIC**:
   - Immediate mode, line numbers, procedural loops (`FOR..NEXT`, `REPEAT..UNTIL`), structured procedures (`PROC`, `FN`).
   - Visual output via Mode 7 Teletext (Ceefax graphics) and GridCore spatial 2D algebra.
3. **Physical Computing with Local Standards**:
   - Robotics and physical computing use uDos tools (uCode BBC BASIC streams: `OPENUP`, `BPUT#`, `BGET#`).
   - Connectivity relies on `uCore-Networking` mDNS / Bluetooth pairing—not raw Python socket code.

## 3. Curriculum Distribution

- **`uCode` (`~/Code/uCode/docs/manual/`)**: The official student coding curriculum (Parts 1 to 7).
- **`SonicScrewdriver` (`~/Code/SonicScrewdriver/docs/manual/`)**: The hardware revival and universal OS curriculum (Parts 1 to 4).
- **`uCore Documentation Surface`**: Aggregates and indexes both tracks side-by-side in the serene Local Wikipedia reader.
